小纸 Pico · 只读固件

浏览器直接烧写，不需要装 ESP-IDF，也不需要命令行。

烧写

  1. 用 Chrome 或 Edge 桌面版打开本页（Safari、Firefox 不支持串口）。
  2. USB-C 数据线连上设备（不是充电线）。
  3. 点下面的按钮，在弹窗里选择串口（一般显示 USB JTAG/serial debug unit）。
  4. 等进度条走完，设备自动重启。
当前浏览器不支持串口，请换 Chrome 或 Edge 本页需要 https 才能访问串口
刷写会覆盖设备上的现有固件，卡片里的书和设置不会被擦除。

如果连不上

  • 拔掉再插一次 USB，等两三秒让系统重新识别。
  • 设备在休眠时 USB 会断开，先按一下电源键唤醒。
  • 还是不行：按住 BOOT 键再插线，直接进下载模式。
  • 端口被别的程序占着（串口监视器、IDE）时，先关掉它们。
这是个人改造固件，基于 MindReset 的 Read Pico 出厂演示固件（Apache-2.0）。 刷写有风险，自行承担；官方不提供支持。
没有浏览器串口？用命令行 
pip install esptool
esptool --chip esp32s3 -p COM3 write-flash 0x0 read-os.bin
固件 2.32 MB · ESP32-S3 · 芯片型号必须一致
源码与说明：github.com/leo123d/read-os
